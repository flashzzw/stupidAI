# 验收记录与本地原始材料

Git 同步本目录顶层的 Markdown 验收报告，保留每次验证的范围、结果、限制和复跑入口。当前任务状态以 [进度表](../PROGRESS.md) 为准。

原始请求、原生会话状态、故障夹具、截图、构建副本和机器可读归档保留在执行验证的本地工作区，由根目录 `.gitignore` 排除。报告中指向这些材料的链接仅在保有对应归档的工作区可用；从远程克隆的仓库不包含它们。既有文件不因首次提交而移动或删除。

需要复验时，按对应报告使用 `tests/` 中的测试入口和隔离环境重新生成证据。报告记录的通过结论只对应当时列明的产物与条件，不代表当前构建已经复验通过。
