## W04.01 · Windows 宿主到 WSL 的最小控制链路

**前置**：已有 WSL 内真实 CLI 正例；本项需要实际 Windows 宿主可执行条件。

**实施与产出**：从 Windows 进程发起目标 WSL 发行版/用户/cwd 的受控 CLI，验证参数引用、路径转换、控制连接、退出/重连与错误报告；按证据选择最小通路，不预定 wsl.exe/socket 协议栈。

**验收**：空格/非 ASCII 路径、不同发行版/用户、CLI 缺失和断连均能定位；实际执行身份、cwd、请求及返回结果正确。只有 WSL 进程内测试时记未执行宿主验收。

## W04.03 · netcap 单会话显式托管

**前置**：W04.02；所用 W01 身份/输入控制及 W02 配置绑定已验证。

**实施与产出**：在暂定候选实现插件面板和默认关闭的托管设置。用户明确选择一个测试会话后，插件带来源提交动作，由平台检查暂停、未决请求、占用、路由及唯一性；显示真实回执与停止原因。

**验收**：设置→平台准入→原生执行→状态更新贯通；重复请求、丢回执、正在原生续行和人工接手不会再发一次。插件不维护第二套 Goal 完成状态或启动旧 Supervisor。

## W04.04 · 插件管理、生命周期与数据兼容

**前置**：W04.03；复用已有事件与操作账本。

**实施与产出**：补本地包/明确来源的安装、启停、升级失败和卸载入口；卸载与数据清理分开。验证停用撤销未执行的自有请求、核对在途动作并保留设置/成果；CLI 插件独立启停。
