# T05 OpenCode HTTP/SSE Adapter

日期：2026-09-29。状态：done。T05 本地验收通过，M2 Alpha 还需 T06。

## 交付

- Go 直接管理 OpenCode 1.18.32 的自有 HTTP/SSE server，接入统一 Application/Web。固定版本能力：创建、发送、历史/恢复、审批、问题和中断；独立 TUI 热接管、原生 Goal、动态 MCP 配置未对外开放。
- 每个托管会话独立原生进程、HOME/XDG、数据库与认证。server.json 记录内部 SessionID、PID/start ticks、epoch、配置指纹；仅 loopback + 随机 0600 token，不操作用户共享后台。所有权和 PTY 租约文件原子写入并 fsync。
- 创建 metadata 对应持久 Operation；发送使用有序时间前缀 + 完整 Operation UUID 的原生 message ID。回执不当作结束，未找到匹配输入返回 Unknown，不重发。
- REST 分页历史、根状态、权限/问题、子会话、PTY 共同核对；SSE 补充流式正文，重复与迟到事件不回退内容，断线通过 REST 恢复。用户 summary 对象与助手 summary 布尔值分别解释。
- 回复绑定原请求、原实例/epoch、原问题顺序与选项约束。Web 支持审批详情和单/多选问题；原端已处理或连接失效的请求不可重答。中断检查自有输入和较新人工输入；原生终态及关联后台均结束才释放占用。
- 已观察的 PTY 可能忽略终端挂断而在 server 崩溃后存活；持久 PID/出生时间/进程组证据保留占用，新 server 的空 PTY 列表不会清除旧工作。确认原进程组退出后才释放。
- 普通会话保留 profile、项目规则、MCP 和显式插件；禁用内置默认插件。最小探测使用独立 profile/cwd，保持原 route 认证/模型，排除工作 hooks/MCP/规则。创建允许 120 秒冷初始化，其他发送超时保持 15 秒。
- 示例、使用说明与正式 Makefile 入口已同步：`make opencode-integration opencode-recovery opencode-contracts`；[CONSOLE.md](../../CONSOLE.md)、[console.example.json](../../console.example.json)。

## 发现、修复与边界

- `/tmp/netcap-console-ex4s47wj` 暴露用户 summary 对象不能解码到 bool；修复后保留联合类型回归。
- 原生拒绝工具会留下 finish=tool-calls，但有 completed 时间及明确拒绝错误。目标 processor 源码确认默认停止循环；根据实际 continue_loop_on_deny 配置识别中断，普通工具错误不直接判结束。
- 原生会补 profile 的 $schema；该注解与排版不算配置漂移，真实配置变化仍阻止旧会话写入。
- `/tmp/netcap-console-rvg66alx` 证明同 server 的“允许并记住”影响另一会话。按设计第 6.1 节采用每会话独立 server/DB。共享配置文件仍是显式共同来源；运行态权限和 MCP 不共享。
- POST /mcp 只改运行态 registry，GET /config 不包含新增项。因此有效配置与 registry 名称都参与指纹；API 未提供同名 MCP 被外部替换后的完整配置证明。原端更改集成前应转人工。
- `/tmp/netcap-console-p5caskxs` 捕获新 server 忘记仍活跃旧 PTY 的失败，已以持久进程组证据修复。仅观察到的新 epoch/旧页面快照不足以验收；回归强制等待新 server URL 出现在完整观察结果。
- 初次显式插件依赖安装超过旧 15 秒创建窗口（`/tmp/netcap-console-7a5er_jb`），现在为已持久化的创建操作保留 120 秒冷启动窗口；不在未知发送上自动重试。
- 当前原生 server 尚无空闲回收。10 个登记会话的初测 Go RSS 为 30,432 KiB，10 个 native server 各 540,368–569,948 KiB；停止控制器后均退出。[资源原始值](T05-resource.json)。每会话隔离的资源代价明确，100 会话规模、按需回收和完整资源目标继续归 T14，不能用当前小样本宣称达标。
- 未调用真实供应商保活、发送外部通知、安装用户 hooks 或迁移用户状态。任意独立 TUI 不自动变成托管会话；原生能力差异不被掩盖。
