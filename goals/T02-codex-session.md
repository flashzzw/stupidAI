## 目标与范围

交付隔离环境中 Web → Application → Codex → 持久状态 → Web 的两轮会话路径。T02 与 T03 共同构成可日常使用的 M1；本项完成后仅作为隔离试用版本。

## 实施步骤

1. 为 `serve` 增加独立配置解析、状态目录和开发构建方式，保留旧 `run` 行为。新入口不调用依赖天气初始化的旧 control.Run。
2. 根据 T01 收敛 Runtime 的最小类型，Codex Adapter 复用现有协议实现；能力未验证时明确标识，避免向 UI 暴露任意 RPC。
3. Application 串行更新状态，耗时 I/O 在受控 worker 中执行。首次发送即持久化 Operation 意图和命令 ID；未确认送达时安全停在 Unknown。
4. 按当前路径需要添加实例/路由引用、会话、Operation、事件和命令回执，保留 schema/native/legacy 标识。库事务不跨网络等待。
5. 实现创建、发送、会话列表、历史、快照和 SSE。静态前端使用设计建议的技术栈，按最小三栏布局呈现真实状态；设置本地鉴权与来源校验。
6. 从相同 Application 接口验证命令幂等、持久化失败和消息关联；浏览器验证真实两轮交互、关页重开及连接过期显示。
7. 未在本项完成的审批/中途恢复明确归 T03，遇到相关状态保留请求与停止自动操作，不能放宽权限维持演示。
