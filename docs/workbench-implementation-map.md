## 状态与证据语义

以下列出 `initial()` 的全部字段。它们是原型内部名；生产模型继续使用自身的领域对象和契约。

| 原型状态 | 生产含义、判据及展示约束 | 负责子任务 |
|---|---|---|
| `checked`、`registered` | 本次诊断结果与持久登记分开；切换路径/配置后旧诊断不能继续显示为当前结果 | [W02.01]、[W04.01] |
| `cli`、`path`、`alias` | Backend、Linux cwd、真实状态目录共享关系；同名/别名不建立独立隔离实例 | [W02.01]、[W01.02]、[W07.01] |
| `ready`、`connected` | 按执行配置与连接方式分别表示认证、控制连接；展示检查来源与时间，未测试供应商显示未知 | [W02.01]、[W02.06]、[W01.02] |
| `goal`、`created`、`task` | 目标版本、Task/Attempt 及各自状态；不能用一个布尔值或 Session idle 判断目标已建/完成 | [W05.01]、[W05.05]、[W06.03] |
| `revision` | **产物版本** r1/r2：需对应文件内容、diff/提交或其他可核对标识；不是配置快照的 revision | [W05.02] |
| `gate`、`gateRevision`、`evidence` | Gate 结果及其产物引用；至少区分通过、失败、未执行、无法判定、已失效，保存检查者/命令/时间/限制与旧证据 | [W05.02]、[W05.03] |
| `control` | `none/platform/checking/human/unknown` 是模拟输入归属。生产 `managed/human_takeover/observed` 不一一对应；交接需核对能力、身份、在途、未决请求及外部输入，不能只改标签 | [W01.01]、[W01.06]、[W05.04] |
| `auto` | 当前范围是否允许后续派发；暂停不等于停止原工具，目标调度与 netcap 自有请求均须遵守撤权 | [W05.04]、[W06.02]、[W04.03] |
| `inflight` | 原生轮次、工具、审批及未知执行的占用；不以连接断开、roster idle 或超时清除 | [W01.05]、[W01.06]、[W05.04] |
| `external`、`draft` | 接入来源与终端未提交草稿；协议历史不能证明无草稿，需原终端处理。切到未验证来源即撤去既有控制能力 | [W01.02]、[W01.03]、[W01.04]、[W01.06] |
| `profile`、`originalProfile` | 原型实际上用 A/B 表示待选/原有**供应商与执行绑定**，不是 Agent Profile。生产分别记录角色配置、CLI 执行配置、ProviderRoute；旧会话绑定不可覆盖 | [W02.01]、[W02.04]、[W05.03]、[W06.01] |
| `snapshot`、`snapshots` | **执行配置版本** v1/v2及历史；同一次执行保留所用版本，候选保存不等于实际生效，不能与产物 r1/r2 合并 | [W02.02]、[W02.04]、[W05.03] |
| `mcp`、`effectiveMcp` | 待选定义与已核对生效选择；实际连接、原生来源、工具清单、使用历史、调用权限仍各自展示。继承不是禁用 | [W02.03]、[W02.04]、[W02.06]、[W02.09] |
| `skills` | 本次可选 Skill 选择；登记/发现/加载/实际使用分别取证，不覆盖强制项目规则或抹掉历史内容 | [W02.05]、[W02.07]、[W02.09] |
| `attempt`、`session`、`sessionCount`、`previousSessions` | Attempt、Session 及旧绑定引用；重连不增 Attempt，新尝试保留原成果。原生 ID 需与执行环境和状态命名空间一起判定身份 | [W01.01]、[W05.01]、[W05.03] |
| `message`、`error`、`log` | 提示、失败原因、最近动作；生产依 Operation/原生回执和事件展示，保留时间、关联对象与证据完整性，不能只存最后五条文案 | [W01.02]、[W05.05]、[W07.03] |
| `scene`、`step` | 演示导航及引导游标；不是业务状态、完成计数或持久进度 | [W03.01]、[W05.05]、[W07.04] |

配置来源展示须分清：模板默认、本次显式选择、原生继承/强制项、实际观察及过去使用。当前 `coverage=recorded_sources_only` 只覆盖被记录来源；内容摘要不证明完整冻结原生环境。无法读取实际清单或来源冲突时保留具体错误与待核对，不自动启用发送。

## 界面验收样例

每个样例应通过生产界面调用对应业务入口，并以原生/持久结果核对界面。已存在的历史测试可复用其固定版本与适用路径；下列完整样例尚未执行。W03.01 的 26 步引导、17 项自由操作、三宽度证据仍只证明模拟交互。

| 样例 | 场景与操作 | 必须观察到的结果及证据 | 负责子任务 |
|---|---|---|---|
| A01 | 配置接入：Windows 路径/缺失 CLI/无权限目录 → Linux 路径；切 Codex/Claude；登记目录别名；选择真实发行版/用户 | 分别显示环境、CLI 路径/版本、配置来源/状态目录、逐项接入能力；错误定位当前配置，别名显示共享，未就绪配置不阻止另一配置，已有文件不被迁移 | [W02.01]、[W01.02]、[W04.01]、[W07.01] |
| A02 | 配置接入：控制连接成功但认证失败 → 在原生支持入口完成认证 → 重新核对 | 连接和认证分别带来源/时间；未发模型测试请求不能报账号已验证；当前配置失败不影响 sibling；新 OAuth 准备 UI/SSE/动态 helper 缺口仍需实测 | [W02.01]、[W02.06] |
| A03 | 交给 Lead：空目标 → 填示例后编辑 → 同一提交重复/丢回执/重载 → 修改需求文件 | 空值不启动；持久化一个 Goal/Task/Attempt 与唯一写执行，重复回到同一对象；约束与采用版本可查，文件变化先显示差异；不是重复点击后只看一条聊天 | [W05.01]、[W06.01]、[W06.02] |
| A04 | 交给 Lead：读取项目后安排 Explore/Implementer/Reviewer | 角色/CLI/范围/依赖/快照可查；Lead 安排来自实际发现，Reviewer 独立上下文；不以固定三行列表算通过 | [W06.02]、[W06.03] |
| A05 | 打回修复：r1 权限测试真实失败 → 修复 r2 → 独立重验 → 检查交付 | 失败带命令/结果/版本，失败不解锁依赖；r1 证据保留，r2 通过方可验收；交付页包含当前成果与限制，交付不隐式提交/发布 | [W05.02]、[W05.03]、[W05.05]、[W06.03] |
| A06 | 打回修复：r2 已通过后产物变 r3；再尝试旧证据交付；另做未执行/无法判定样本 | r2 证据可读但不批准 r3；无法证明不受影响则重验；未知执行仍可能改成果时也不交付；结果维度与执行空闲分开 | [W05.02]、[W05.05]、[W06.05] |
| A07 | 人工接手：工具/审批在途时申请 → 结束后核对 → 人工发送 | 后续自动化立即暂停、原工具仍可观察；没有完整空闲与输入核对不开放发送；人工发送保留原 ID/历史，自动派发仍暂停，不借 `resume` 重新授予自动化 | [W01.06]、[W05.04]、[W04.03] |
| A08 | 人工接手：原终端有草稿、新外部输入、仅观察来源、独立前台；交接中再次暂停 | 草稿需原终端处理；仅观察没有发送/审批/停止权；新外部输入或迟到暂停撤销旧核对；未验证独立前台保留原端入口，不启动替代执行者 | [W01.02]、[W01.03]、[W01.04]、[W01.06] |
| A09 | 人工接手/恢复：发出消息后断连或丢回执 → 重连；另做关窗/休眠/重启 | 保留最后时间、原消息/轮次/身份和占用，先只读核对，不重发、不新建 Attempt、不清用户暂停；Windows 分别有宿主证据 | [W01.05]、[W05.04]、[W07.02] |
| A10 | 交给 Lead/恢复差异：选/排除 Skill、MCP；查看原生强制项与插件带入同名项 | 库版本、计划选择、实际来源、工具清单、使用证据与权限分列；必要资源不可用阻断依赖任务；排除冲突有原因，恢复继承不能冒充禁用 | [W02.03]、[W02.06]、[W02.07]、[W02.08]、[W02.09] |
| A11 | 恢复差异：在途保存 MCP 变更 → 空闲后准备 → 明确应用 → 下一轮 | 保存期间仍用 v1；原生核对通过才晋升 v2，旧轮次/产物证据关联不变；Codex 等原线程卸载，Claude 仅关闭空闲自有 query，sibling 继续；审批/未知不晋升 | [W02.04]、[W02.06]、[W05.03] |
| A12 | 恢复差异：相同选择、旧页面基线、应用丢回执、应用期间 crash、实际版本不可读 | 相同选择不增版本；过期基线拒绝；查持久操作与原生版本后决定晋升，未知保留候选且不重放；迟到成功不能恢复已撤销的控制权 | [W02.04]、[W02.06]、[W05.04] |
| A13 | 恢复差异：原绑定恢复 → 切供应商/Backend/状态目录 → 尝试恢复 → 显式新尝试 | 普通恢复保持 Session/Attempt/快照；切绑定阻止普通恢复；有在途先核对，新 Attempt 关联前驱、原成果和新快照，旧原生 ID 不传给新绑定，新尝试不自动运行 | [W01.01]、[W02.04]、[W05.03] |
| A14 | 五场景：导航/详情/字段/键盘/窄窗；重载或返回原对象 | 生产导航不重置业务，展开不产生写入，错误和等待可读，焦点不丢失；引导步骤不计作业务完成；不迁移原型 reset 的清空行为 | [W05.05]、[W07.01]、[W07.04] |
| A15 | 能力详情：CLI 插件与平台插件分别查看、启停；netcap 接手后禁用并重启 | 两层宿主、组件、版本和影响范围分列；撤销未执行自有请求、保留在途与成果，重启不双重调度；原型静态标签不能作为此项证据 | [W02.08]、[W04.03]、[W04.04] |
